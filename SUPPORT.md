# Getting help

* **Something is wrong** (a crash, a result file read wrongly, a verdict you think is
  wrong): open a [bug report](https://github.com/dundysm/inference-doctor/issues/new?template=bug_report.yml).
* **Your benchmark tool's output is not read yet:** open a
  [format request](https://github.com/dundysm/inference-doctor/issues/new?template=format_request.yml).
* **You ran it on a real change:** tell us how it went in a
  [benchmark feedback](https://github.com/dundysm/inference-doctor/issues/new?template=benchmark-feedback.yml)
  issue. This is the most useful report right now.
* **Questions, how-to, ideas:** start a thread in
  [Discussions](https://github.com/dundysm/inference-doctor/discussions).

When asking about a result, include the command you ran, the version
(`inference-doctor --version`), and the output; `--json` output is best. Redact prompts,
credentials, private model names and customer data first.
